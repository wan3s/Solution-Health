# Параметры отказоустойчивости систем

| Система | Стратегии retry | Размер таймаута | Действия при fallback |
| ---- | ---- | ---- | ---- |
| 1C (полисы) | 3 попытки с exp backoff: 100мс, 200мс | p99 времени отклика через год должен быть меньше 1с. С учетом стратегии retry должно получиться так: timeout + 100 мс + timeout + 200 мс + timeout < 1c. То есть таймаут не больше ~233 мс | Полисы можно кешировать и в случае недоступности 1с доставать данные из кеша |
| Платежный шлюз | 3 попытки с fix delay в 1с, если платёжный шлюз поддерживает идемпотентность. Если не поддерживает, то без ретраев | Пусть p95 времени ответа - 500мс. Тогда таймаут = 650 мс | Либо использовать альтернативный платежный шлюз, либо вернуть ошибку. |
