# Анализ текущей интеграционной архитектуры

| Проблема | Признаки | Влияние на приложение |
| --- | --- | ------|
| Частая недоступность 1С | * Техподдержка утверждает, что из-за этого онлайн проверка не находит полис (отзыв Product Owner) <br> * Jira INT-003 <br> * SD-001 | Нужно думать над подходящим вариантом Fallback в случае недоступности 1C, либо над выносом проверки полисов из 1С |
| Отсутствие идемпотентности при записи онлайн | * Руководитель контакт центра подсвечивает проблему, с которой в половине случаев обращаются клиенты: клиент записался онлайн, а врач его не принял <br> * Менеджер по развитию тоже подсвечивает эту проблему после запуска акции со скидкой на анализы при онлайн записи <br> * Техлид команды расписания явно говорит про отсутствие идемпотентности <br> * Jira INT-005 <br> * SD-003 | Нужно добавить ключ идемпотентности при онлайн записи|
| Клиенты не могут просматривать результаты анализов | Руководитель контакт-центр рассказывает, что часто к ним клиенты обращаются с просьбой предоставить результаты анализов | Добавить функционал |
| Отсутствие масштабирования чтения базы с раписанием | * Техлид команды расписания явно про это говорит <br> * Врачи жалуются на проблемы с редактированием расписания <br> * Тикет INT-009 | Нужно подумать над блокировками и репликами в БД |
| Отсутствие ретраев во время загрузки результатов анализов из лабораторий в CRM | * Отзыв DevOps инженера <br> * Jira INT-002 | Добавить пакетную выгрузку данных с ретраями, чтобы к утру следующего дня все анализы были доступны |
| Отсутствие версионирование API сервисов | Разработчик интеграций рассказывает историю, как 1С стал возвращать XML вместо JSON | Добавить версии API |
| Отсутствие компенсаций для распределенных транзакций | * Jira INT-001: При таймауте платежного шлюза деньги списываются, а платеж не фиксируется | Подумать над внедрением паттерна Saga <br> * SD-002 |
| Нет защиты от SQL-инъекции | Тикет INT-006 | Добавить защиту |
| Нет инструментов мониторинга (логи, трейсинг) | Тикет INT-007 | Повысить observability |
